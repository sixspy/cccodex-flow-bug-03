## 幂等落库口径

正确性口径只取一种——**整批原子（atomic batch）**，不与“部分留存”混用：

| 环节 | 规则 |
|------|------|
| 撞钥判定 | 同批任一行撞到幂等钥匙，整批同一判定：全部跳过；判重按去空白 + 大写折叠，变形 key 无法绕过 |
| 跳过计数 | 跳过行数计入 `land_batches.skipped` 与 `land_events`，写入 0 行，绝无半写入 |
| 落库 | 整批写入与 `flows.landed` / 状态在同一事务内完成 |
| 回滚 | 原子整笔：按批一次撤销全部行，并强制把列表与库存对齐 |
| 并发 | 同批落库串行（流级进程内锁 + SQLite `BEGIN IMMEDIATE`），后到者不重复写并记争用 |
| 核对 | 面板/列表旁挂策略标题与一致性横幅：`列表已落库合计 = 库存`，出现分叉或半写入即报红 |

页面顺序：落库列表 → 撞钥详情（整批判定、批次事件）→ 回滚页（库存与列表对照、回滚记录）。
